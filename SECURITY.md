# Security Policy and reporting a Vulnerability

Onym Core is an independent fork of Stellar Core. It is **not** covered by the
Stellar Development Foundation's bug bounty program.

To report a vulnerability in Onym Core, use GitHub's private vulnerability
reporting for this repository (Security tab → "Report a vulnerability"). Please
do not open a public issue for security problems.

If the vulnerability also affects upstream Stellar Core, please report it to
the Stellar Development Foundation as well, through their
[bug bounty program](https://www.stellar.org/bug-bounty-program/).
