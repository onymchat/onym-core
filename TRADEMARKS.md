## How this project refers to Stellar

This repository mentions Stellar only to identify things accurately:

- **Attribution**: Onym Core is derived from Stellar Core, and the upstream
  copyright notices name the Stellar Development Foundation and contributors.
  These notices are kept as the Apache License 2.0 requires.
- **Technical identification**: upstream identifiers such as the `stellar` C++
  namespace, the Stellar Consensus Protocol, XDR type names, network
  passphrases and the `stellar-core.cfg` file name stay in the source code
  where renaming them could break compatibility. See
  [FORK_ORIGIN.md](./FORK_ORIGIN.md#deliberately-unchanged-identifiers).
- **Inherited documentation**: much of `docs/` comes from upstream and still
  uses upstream names.

None of these uses means the Stellar Development Foundation endorses,
sponsors or supports Onym Core.

## What this project does not do

Following the Stellar Development Foundation's
[Brand Policy](https://stellar.org/brand-policy) (effective January 21, 2025),
Onym Core:

- does not use "Stellar" or other Stellar marks in its product name,
  executable name, package names or branding;
- does not use the Stellar logo;
- does not present itself as official Stellar software or as a release of
  Stellar Core.

The software includes the statement "This is independent software, not
affiliated with, sponsored or endorsed by the Stellar Development Foundation."
in this repository's README and NOTICE, in the output of `onym-core version`,
and on the node's HTTP root page.

Questions about Stellar marks should go to the Stellar Development Foundation.
